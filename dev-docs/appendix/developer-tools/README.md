# Developer Tools

Smartstore includes small utilities for maintaining assets, packaging extensions, and testing the Web API. They are located in the repository's `tools` directory and are intended for development and release workflows.

| Tool | Purpose | Source code |
| --- | --- | --- |
| [Smartstore Icon Generator](icon-generator.md) | Compares Bootstrap Icons SVG collections and creates the reduced icon subset used by Smartstore. | [GitHub](https://github.com/smartstore/Smartstore/tree/main/tools/Smartstore.IconGenerator) |
| [Smartstore Packager](packager.md) | Creates installable ZIP packages for compiled Smartstore modules and themes, either interactively or from the command line. | [Desktop](https://github.com/smartstore/Smartstore/tree/main/tools/Smartstore.Packager) · [CLI](https://github.com/smartstore/Smartstore/tree/main/tools/Smartstore.Packager.Cli) |
| [Smartstore Web API Clients](web-api-clients.md) | Provides Windows and JavaScript reference clients for composing, sending, and inspecting Smartstore Web API requests. | [.NET](https://github.com/smartstore/Smartstore/tree/main/tools/Smartstore.WebApi.Client) · [JavaScript](https://github.com/smartstore/Smartstore/tree/main/tools/Smartstore.WebApi.Client.JavaScript) |
